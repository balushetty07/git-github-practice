# Git & GitHub Practice Lab

This repository is my personal sandbox for learning Git, Github, and the command line.

## What I am Learning

- PowerShell Commands
- Git repositories and commits
- Branches and merging
- GitHub collaboration

## Git Commands I Have Practised

- `git init` — initialise a repository
- `git status` — check the repository state
- `git add` — stage changes
- `git commit` — save a local snapshot
- `git remote` — manage remote connections
- `git push` — upload commits to GitHub
